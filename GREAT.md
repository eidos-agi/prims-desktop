# Great Prim

What a **great-great** Prim.app scores as. `scripts/learn` measures this.
Target **90 / 100**. 100 is Preview-grade: Finder, Mail, Messages, and
“send me the prim” all land on the file, every registered use hosts, Save
writes the pack, and the surface is a place you walked into.

This is not a SaaS scorecard. Prim.app is the document owner. The website
is a view. The host is not the file.

## Dimensions

| id | pts | Great-great |
|---|---:|---|
| land | 20 | Double-click, Mail, Messages, `open -a "Prims Desktop" file.prim` open Prim.app on the citing tool — not a zip, not a tab, not “This tool runs locally.” |
| host | 15 | Every registered type hosts. Every citing surface and connector is choosable. Process tools stay local. |
| file | 15 | File → Save writes the zip. Detect still returns the same kind. No sidecar store. In-memory editor mutations export into `document.data`. |
| place | 15 | Each surface is a received document. OBIF: one scrolling book (cover, mark, type, voice, ground) in the Prim.app window (~672×524), first screen holds, no CMS tabs, no COVER stamp. |
| uses | 15 | Finder default handler. Copy / Export. Agent can point at a path. Website remains a view. Docket, deck, invoice, session, arcade, log, EMF/ORF/OPF/ODWF/OCSF/OSF/OBF, brand — each opens. |
| catalog | 10 | A new row in `registry/registry.json` appears in the host without a Swift face per type. |
| honest | 10 | Do not claim the editor’s memory is the file until export works. Fallback text is only for process tools. Pixel proof is a Prim.app window (`screencapture -l`), not Paseo HTML. |

## Grades

| score | means |
|---:|---|
| 0–39 | Brochure. Tests or a demo tab, not a document app. |
| 40–69 | Host exists. Some types open. Save identity maybe. The folio is still a lab. |
| 70–89 | People can work a dropped `.prim`. Gaps are Mail/Messages, mutation Save, or a plate that still looks like a CMS. |
| **90–99** | **Great-great.** Preview-for-`.prim` on this Mac. Remaining is notarize, a rare type, or polish. |
| 100 | Notarized, every use proven in the real window, Mail and Messages included. |

## Proof that counts

- Prim.app window capture: `scripts/capture-window` → `.learn/proofs/`
- HostTests + testr attempt (Go CLI, never hand-written JSON)
- Observations an agent wrote **after looking at the PNG**: `.learn/observations.json`

Paseo proof HTML and `http://127.0.0.1:8799` do not score `land` or `place`.
